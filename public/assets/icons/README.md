# Iconos pendientes

Los PNG neutros son placeholders temporales, no el icono diseñado de TMB Agent.
Las iniciales de los módulos son también placeholders.

Añade aquí los archivos originales de Incidencias, DEA, Bobines, Cómputo y Miralín,
y asigna su ruta relativa en `src/modules.js` (por ejemplo `./assets/icons/incidencias.png`).
Cuando se aporte el icono exacto de TMB Agent, sustituye los PNG del manifest y del HTML.
